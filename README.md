# A Ascensão do Ciborgue 🤖🚀

## 📝 Sobre o Projeto

**Rise of the Cyborg** é um jogo de ação e plataforma 2D com temática *cyberpunk* distópica. O projeto explora uma discussão filosófica e ética sobre o avanço da Inteligência Artificial e a automação de uma forma interativa.

No controle do agente modificado **Luke**, o jogador deve atravessar 5 continentes para deter os planos de dominação global e recuperar o controle do planeta contra um exército de máquinas hostis.

---

## 🎮 Funcionalidades e Mecânicas Principais

* **Combate Híbrido Dinâmico:** Alterna estrategicamente entre ataques de curto alcance (Lâmina Cibernética) e longo alcance (Disparos Laser).
* **Loop de Jogabilidade Rítmico:** Enfrente patrulhas, colete engrenagens de forma probabilística e decida em tempo real entre usar-las para auto-reparo imediato ou guardá-las para evolução de habilidades.
* **Progressão por Continentes:** 5 capítulos diferentes com curva de dificuldade progressiva, design de níveis verticais e trilha sonora adaptativa.
* **Combate contra Chefões:** Enfrente o robô líder ao final de cada cenário para hackear as Torres de Sinal do planeta.

---

## 🛠️ Tecnologias e Ferramentas Utilizadas

* **Engine:** Unity 2D (Física 2D, Colliders, Rigidbodies e Tilemaps)
* **Linguagem:** C# (Scripts de movimentação, sistema de combate e interface)
* **Artes e Animações:** Piskel (Spritesheets desenvolvidas em Pixel Art)
* **Landing Page:** HTML, CSS e Tailwind CSS
